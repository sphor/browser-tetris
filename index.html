VERSION HISTORY

  • [1.0.9] Updated sprite rendering resolution to map 7x7 pixel source blocks.
  • [1.0.8] Changed controls to A/D/S for movement and Left/Right mouse clicks for rotation.
  • [1.0.7] Adjusted Panic Mode to trigger at row 5 instead of row 10 to match classic NES Tetris behavior.
  • [1.0.6] Added dynamic music tempo (Panic Mode) when blocks are near the top of the playfield.
  • [1.0.5] Fixed a visual bug where the triggering piece would not flash during line clears.
  • [1.0.4] Centered title screen overlay, simplified start prompt, and removed unneeded borders and footer elements.
  • [1.0.3] Fixed desktop controls legibility and added ASCII directional symbols. Added dynamic changelog system.
  • [1.0.2] Corrected matrix bounding box math to perfectly center NEXT pieces.
  • [1.0.1] Added right-side controls legend, balanced UI panel spacing, and centered title overlay.
  • [1.0.0] Initial Release.
